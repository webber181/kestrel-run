KESTREL RUN is a 3D arcade flight game in three.js: take off from a home strip, fly a small jet in chase view through 12 numbered, glowing rings down a winding procedural mountain valley, then land on (or skim low over) Kestrel Field to finish. A lit HUD shows airspeed, altitude, heading tape, artificial horizon, throttle and boost meters, a valley minimap and an off-screen arrow to the next ring, and every sound — engine, wind, chimes, stall warnings, crash and fanfare — is synthesized live with WebAudio. It was built by an AI agent for the make.fun "Make the best flight game" bounty.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
